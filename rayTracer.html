Software Ray Tracer

A small CPU ray tracer written in JavaScript that casts rays through a scene of spheres and writes the result pixel-by-pixel to an HTML canvas.

Run the renderer All graphics projects

Features

  • Ray-sphere intersection tests using a quadratic equation.
  • Closest-hit selection and surface-normal calculation.
  • Background gradient for rays that miss the scene.
  • Phong-style diffuse and specular lighting with hard shadow tests.
  • Single-bounce reflections for selected spheres.
  • 50 jittered samples per pixel to reduce sampling artefacts.
  • Pixel output through the Canvas 2D context.

Concepts applied

  • Vector arithmetic, dot products, normalisation, and ray parameterisation.
  • Analytic ray-primitive intersection and nearest-hit tracing.
  • Surface normals, lighting, shadows, and reflections.
  • Camera viewport construction and stochastic pixel sampling.
